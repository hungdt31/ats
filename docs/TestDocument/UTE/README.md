# UTE - Unit Test Evidence

Tài liệu Unit Test Evidence cho từng màn hình/chức năng của hệ thống **ATS**.

## Quy ước kết quả test

| Ký hiệu | Ý nghĩa |
|---------|---------|
| ○ | OK - Pass |
| × | NG - Fail, chưa giải quyết |
| ×→○ | NG - đã giải quyết |
| － | Không phải đối tượng test |
