# ITE - Integration Test Evidence / Test Data

Tài liệu dữ liệu test chuẩn bị cho Integration Test của hệ thống **ATS**.

## Danh sách file

| File | Nội dung |
|------|---------|
| [ITE_Master_Test_Data.md](./ITE_Master_Test_Data.md) | Toàn bộ dữ liệu test: users, jobs, applications, interviews, OTP, files |

## Hướng dẫn sử dụng

1. Chuẩn bị dữ liệu theo bảng trước khi chạy test
2. Dữ liệu **BẮT BUỘC** phải có trước khi test bất kỳ scenario nào
3. Dữ liệu **TÙY CHỌN** chỉ cần cho test case cụ thể
4. Reset dữ liệu sau mỗi test session để đảm bảo tính độc lập
